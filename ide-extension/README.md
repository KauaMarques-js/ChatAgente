# ChatAgente 0.2.0 — extensão embutida

Alvo: distribuição autônoma VSCodium 1.143.17232 / Code OSS, Windows x64. O protótipo Electron anterior permanece disponível por `dev:legacy`. Instalar em `resources/app/extensions/chatagente` com os quatro módulos atuais em `runtime/` (`agent.cjs`, `workspace.cjs`, `codex-agent.cjs`, `chatgpt-auth.cjs`) e dependências de produção em `node_modules/`, conforme o build externo. Não incluir credenciais, `.env`, perfis ou dados da máquina de build. A extensão não busca runtime em `src/` no produto.

O painel abre no primeiro uso e pelo comando `chatagente.open`. Terminal, explorador, editor e Git usam a IDE nativa. `Ctrl+'` alterna o terminal. Em projetos com várias raízes, cada envio pede a seleção da pasta; trocar a raiz reinicia o contexto. ChatGPT lista modelos reais da conexão; Codex aceita modelo explicitamente informado ou o padrão do CLI, sem catálogo inventado. Enviar com Ctrl+Enter também funciona. O histórico fica somente na memória do extension host. A status bar mostra agente e modelo mesmo com o painel fechado.

ChatGPT usa o OAuth do runtime, abre somente `https://auth.openai.com`, não oferece API key e mantém as aprovações por escrita/comando. Registros OAuth são cifrados com AES-256-GCM; a chave fica no SecretStorage da IDE. `host.json` contém apenas metadados públicos do cliente OAuth. Arquivos ficam em `context.globalStorageUri`, nunca no perfil Electron original. Codex herda a configuração e o login locais normais do usuário (`CODEX_HOME` explícito, quando presente; caso contrário o padrão do CLI), tanto no terminal de login/logout quanto no SDK, com autorização explícita por tarefa, preservando `workspace-write` e `approvalPolicy: never` do runtime. Não há novos limites de rodadas, repetição ou tempo de tarefa.

Escritas por Workspace recusam arquivos com buffers não salvos, sem salvar ou descartar conteúdo automaticamente, e preservam a validação original de caminhos, links, segredos e conflitos. Codex usa processo externo: exige buffers salvos ao iniciar; alterações não salvas criadas durante uma tarefa e escritas via shell não passam pelo guard de Workspace. O editor continua mostrando seus conflitos nativos de disco. Interromper cancela o signal do agente/login; alterações já realizadas não são revertidas.

Webview com CSP restritiva, recursos locais limitados à mídia, mensagens validadas no extension host e saídas renderizadas com `textContent`. Erros são apresentados com diagnóstico e redação de tokens conhecidos e padrões de credenciais; headers não são registrados. Os testes usam dados sintéticos e não autenticam contas nem consomem inferência.

Verificação: `npm --prefix ide-extension test`, `node --check ide-extension/extension.cjs`, `node --check ide-extension/media/chat.js` e `npm test` na raiz. O teste do guard importa Workspace da árvore fonte somente no ambiente de desenvolvimento. Login real, inferência e smoke test visual dependem da IDE empacotada e de uma conta elegível; não são simulados no produto.

APIs consultadas em 08/11/2026: [Webviews/CSP](https://code.visualstudio.com/api/extension-guides/webview), [VS Code API — SecretStorage, TerminalOptions, WebviewViewProvider](https://code.visualstudio.com/api/references/vscode-api). Contratos OpenAI reutilizados integralmente do runtime existente e do SDK instalado.

`chatagente.selectAgent` está na paleta e na status bar: argumento opcional `chatgpt`/`codex`, sem argumento abre QuickPick. A API retornada por activate expõe apenas `getState(): { backend, project, busy, model, connected }`, sem histórico ou segredos. Testes reais da IDE devem usar --user-data-dir, --extensions-dir e CODEX_HOME temporários, sem inferência ou contas pessoais.

`auth-lock.cjs` usa named pipe exclusivo por perfil para coordenar chave AES-GCM, login, refresh e logout entre janelas Windows. O registro é recarregado antes de cada operação e o bloqueio é liberado automaticamente ao fechar o processo. Enter envia e Shift+Enter quebra linha. Teste nativo da IDE e abertura normal aprovados no incremento 8; login/inferência de conta seguem não verificados.
